 ### Option 2: Use hostPath PV (quick and dirty, NOT production)                                                                                                                                                   
                                                                                                                                                                                                                   
 On the host node, create a directory:                                                                                                                                                                             
                                                                                                                                                                                                                   
 ```bash                                                                                                                                                                                                           
   mkdir -p /mnt/outline-data                                                                                                                                                                                      
 ```                                                                                                                                                                                                               
                                                                                                                                                                                                                   
 Create a pv-outline.yaml on the host cluster:                                                                                                                                                                     
                                                                                                                                                                                                                   
 ```yaml                                                                                                                                                                                                           
   apiVersion: v1                                                                                                                                                                                                  
   kind: PersistentVolume                                                                                                                                                                                          
   metadata:                                                                                                                                                                                                       
     name: outline-pv                                                                                                                                                                                              
   spec:                                                                                                                                                                                                           
     capacity:                                                                                                                                                                                                     
       storage: 10Gi                                                                                                                                                                                               
     accessModes:                                                                                                                                                                                                  
       - ReadWriteOnce                                                                                                                                                                                             
     persistentVolumeReclaimPolicy: Retain                                                                                                                                                                         
     hostPath:                                                                                                                                                                                                     
       path: /mnt/outline-data                                                                                                                                                                                     
 ```                                                                                                                                                                                                               
                                                                                                                                                                                                                   
 Then create your PVC in vcluster normally — it will bind to this PV.                                                                                                                                              
                                                                                                                                                                                                                   
 ⚠️ hostPath is unreliable for multi-node clusters. Use only if your pod is pinned to one node.
